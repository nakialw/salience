# Example platform configs

These are **samples only** — not linked by `./install.sh`.

Copy and edit for your machine:

```bash
# Claude Code (optional)
cp config/examples/claude-settings.json ~/.claude/settings.json

# Gemini (optional)
cp config/examples/gemini-settings.json ~/.gemini/settings.json
```

Do **not** commit personal `settings.local.json` or Codex project paths. Create those locally.
